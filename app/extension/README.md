# 文案程序 · YouTube 数据抓取(Chrome 插件)

在 YouTube Studio 打开某条视频的「数据分析」页,点右下角「一键抓取并下载」,
插件会依次打开 概览 / 覆盖面 / 互动 / 观众 四个标签(约 40 秒,期间别动页面),
把指标、留存曲线和 Studio 的原始数据下载成一个 yt-data_视频ID_时间.txt 文件(内容是 JSON),拿去给 AI 分析。
面板「设置」里还有「抓取并发送到文案程序」:直接存进标题对得上的那篇文案任务(需要文案程序在本机开着)。

## 安装(只需一次)
1. Chrome 地址栏打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」,选这个 `app/extension` 文件夹
4. 只下载文件不需要开文案程序;要「发送到文案程序」时程序得开着(默认 http://localhost:8080,不是这个地址就在面板「设置」里改)
5. 更新插件:覆盖文件后在 chrome://extensions 里点插件卡片上的刷新按钮,再刷新 Studio 页面

## 用法
- YouTube Studio → 内容 → 点某条视频 → 数据分析 → 右下角面板点「一键抓取并下载」,文件在浏览器的下载文件夹里
- 同一个标题跑过多篇文案时,面板会列出来让你选是哪一篇;选过一次以后按视频 ID 自动对上
- 抓完到文案程序的任务详情页看「真实数据(YouTube)」:留存曲线按章节对齐,每章流失多少、掉人最多的句子
- 「下载分析包」= 推出去的文案 + 程序打分 + 真实数据,发给 AI 复盘

## 说明
- 只读 Studio 页面上已经显示的数据和它自己的数据接口返回,不改任何东西,也不发到别处
- 原始数据存 `app/data/yt_analytics/`(不入库);任务文件里留指标、曲线和 YouTube 的说明句(会随任务文件入库)
- 每句在视频里的时间是按字数比例估的,会差几秒
- 隔几天再抓一次,任务里会多一条历史记录,可以看数据怎么变
