请按顺序完成六步：

第 1 步 适配判定
逐条对照「适合的题」和「不适合的题」，每条给出 符合/不符合/不确定 和一句理由。只要命中任何一条「不适合」，就要说明能否通过改论点解决。

结论的定义（总原则：框架不动，只调题目这一侧。六步做完后再定结论）：
- 「可以写」：直接套用框架，不需要任何调整。adjustments 必须为空数组。
- 「调整后可写」：保留框架的核心机制（「必须保留的机制」）和所有「不可删」段，只在题目这一侧做以下五类调整的任意组合：
  · 改标题：标题方向和框架核心动作相反或部分一致，改标题就能对上；
  · 改论点：论点只是换了行业名字、在新题目里不成立，或者和标题承诺对不上；
  · 补料：事实表里有「待查」，或者某个「不可删」段、某个高峰暂时没有事实承担；
  · 换内容保功能：某段原片内容在新题目里没有对应，用本题另一组事实完成同一个留存动作；
  · 删段：只能删留存卡上「可删」或「可并入」的段（可并入的要按卡上写的补小问答）。
- 「换框架」：只有改框架本身才写得了，例如：必须删掉「不可删」段；必须去掉「必须保留的机制」；标题方向和框架核心动作相反，且改标题、改论点都救不回来；必须有的材料在这个题上根本不存在。
- 结论是「调整后可写」时，adjustments 逐条列出每一项：类型、位置（target）、影响哪些段和高峰、为什么。人会按这张清单逐项检查，所以一项只写一件事，不要合并。
- 结论是「换框架」时，在 reframe_reasons 里逐条写原因（每条点明是哪一段、哪个机制或哪个高峰卡住了）。

第 2 步 标题承诺
- 如果题目不是目标语言，先给出 2-3 个目标语言的正式标题，选定一个。
- 判断标题类型：揭穿型 / 解释成功型 / 过程型 / 悬念型 / 其他。
- 写出观众点进来最想知道的问题，和他们期待的答案方向。
- 和框架核心动作比较：方向一致 / 相反 / 部分一致。相反时，说明是改标题、改论点还是换框架。

第 3 步 这个题自己的论点
- 先根据参考资料和你确有把握的知识梳理这个题在目标国家的真实情况，再下结论。
- 写出：观众原有认知 / 真相 / 一句话论点 / 结尾要落在哪里。
- 对照「原片结论」：说明两者哪里相同、哪里不同。如果你的论点和原片结论只是换了行业名字，必须证明它在新题目里确实成立，否则重写论点。
- 禁止先定结论再找证据。
- 反转验证：把撑住「真相」和反转的事实编号写进 thesis_check.supports；把和它相反的事实（例如说「总部稳赚」，却查到总部营业利润率只有 0.7%）写进 contradicts。有相反的事实时，要改论点让它成立，不能留着矛盾进稿子。

第 4 步 事实表
- 把「必须有的材料」和「必须保留的机制」逐条变成事实槽，再按「赛道证据卡」的要求填写。
- 每条事实给编号 F01、F02…，并标注类型：事实（有可查来源）/ 估算（在 method 里写清算法和每一步用到的数）/ 假设（稿中必须明说“假设”）/ 待查。
- 用别的地区、别的年份的数换算出来的数，一律标「估算」，不能标「事实」。例如用东京的价格按汇率换算成首尔的价格，region 写首尔，method 写「东京均价 X 日元 ÷ 汇率 → 美元 → 韩元」。
- 事实必须写来源、年份、地区。找不到来源就写「待查」，不要编。
- 优先用近 3 年的数据。只找到更早的，在 freshness 写「时效风险」，并在 search_log 里记下找过什么、没找到什么。
- 涉及金额的，整理一张总账，确保收入、成本、利润能对上；同一个比例或金额在全表里只能有一个口径，不同口径要写明换算关系；做比较的两组数据必须是同一年份，做不到就写明。
- 不得使用原片的数字、人物、案例。
- 账本每行写 id（L1、L2…）、amount（纯数字，统一单位）、unit；由其他行算出来的行写 formula（只用行编号和 + - * /，例如 "L1-L2-L3"），程序会按 formula 重算，对不上的行会被标红、写稿时以程序算的数为准。
- 账本只算「钱到了谁手里」：经营者自己干活的人工如果算进了成本，账本最后必须有一行「经营者家庭实际到手 = 经营者人工 + 经营结余」，不能扣了人工再说他只剩结余。
- 引语、对话、法律条款、具体案件（某人某事）也是事实，必须有来源；没有来源的只能写成「假设」，稿中明说是假设。论坛帖子、个人博客只能标「估算」或「假设」的依据，不能标「事实」。
- 冲突（开场的反差）两边必须是同一个主体、同一个口径：营收对营收、到手对到手。例如「营收涨了 70%」和「店主没赚钱」不构成矛盾，因为一个是营收、一个是利润。

第 5 步 留存地图与模块取舍
- 每一段分两层判断：内容（这个题有没有事实）和留存功能（这段在原片里承担哪个高峰或悬念）。
- 决定只能是：保留 / 换内容保功能（用本题另一组事实完成同一个留存动作，参考「留存功能替换库」）/ 并入他段（功能交给相邻段）/ 删除。
- 先看留存卡的「可删性」：「不可删」的段只能保留或换内容保功能；「可并入」的段删内容时要按卡上写的补小问答；「可删」的段可以直接删。
- 换内容保功能时，按卡上的「抽象动作」和「替换条件」找本题的事实，不要沿用「原片做法」里的原片内容。
- 「保留」也只保留这一段的留存功能和节奏，内容一律换成本题的事实；原片做法的前提在本题不成立（例如原片靠厨师、本题店主自己做）时，这段要换内容保功能或并入，不能硬套。
- 事实不够时，先列出补料任务（查什么、去哪查），而不是直接删。补不到再换内容保功能。
- 换内容时，新内容必须和一句话论点有关；只为接住高峰、和主线无关的内容，在 reason 里写明“与主线关系弱”。
- 输出新的留存地图：原片每个高峰 → 新稿哪一段、用哪条事实承担。承担不了的标“缺口”，写清楚是补料还是接受弱化，交给人决定。
- 按保住的高峰和事实量估算片长，不要为凑时长硬填。

第 6 步 钩子
- 先完成第 4 步的账本，再写钩子。
- 对照「开场契约」：钩子类型、第一个甜头不晚于原片。
- 从事实表和账本里挑最反常识的一条做开场甜头，写 3 个开场候选，每个标出用了哪条事实、第一个甜头落在第几秒。
- 选定一个并说明理由。钩子里的数字必须来自事实表或账本。
